# 같이 성장 북마크

팀에서 함께 보는 링크 모음이에요. **회사 메일(@ybm.co.kr)로 인증한 사람만** 보고 등록할 수 있어요.

- **섬네일**: 이미지를 따로 저장하지 않아요. 화면을 열 때 URL로 [WordPress mShots](https://s0.wp.com/mshots/v1/)(무료 캡쳐 서비스)에서 캡쳐를 불러와요. 처음 등록한 링크는 캡쳐가 만들어지는 데 몇 초~수십 초 걸리고, 캡쳐가 안 되는 사이트는 파비콘+도메인으로 대신 보여줘요.
- **키워드**: 서버(Apps Script)가 페이지의 제목·설명·meta keywords를 읽어 자주 나오는 단어 5개를 뽑아요.
- **링크**: 상세 페이지 없이 카드를 누르면 새 창으로 열려요.
- **인증**: 처음 들어오면 회사 메일로 인증번호 6자리를 받아 입력해요. 한 브라우저에서 90일 동안 다시 묻지 않아요. 인증 메일은 시트 주인의 Gmail에서 나가요(하루 100통 한도).
- **삭제**: 내가(같은 회사 메일로) 등록한 카드에만 삭제 버튼이 보여요. 인증 기능 전에 올린 카드는 시트에서 직접 지워요.

## 처음 한 번 설정하기 (5분)

GitHub Pages는 저장 공간이 없어서, 북마크는 **Google 시트**에 모아요.
설정 전에는 "체험 모드"로 동작해서 이 브라우저에만 저장돼요.

1. [Google 시트](https://sheets.new)를 새로 만들어요. (이름 예: `북마크 공유`)
2. 메뉴 **확장 프로그램 → Apps Script**를 열고, 기본 코드를 지운 뒤 `apps-script.gs` 내용을 통째로 붙여넣고 저장해요.
3. 오른쪽 위 **배포 → 새 배포** → 유형 **웹 앱** 선택
   - 다음 사용자 인증 정보로 실행: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
   - 배포 → 권한 허용(외부 URL 읽기·시트 쓰기) → **웹 앱 URL**(`https://script.google.com/macros/s/…/exec`) 복사
4. `bookmark/index.html`의 `const API_URL = '';` 따옴표 안에 그 주소를 넣고 커밋·푸시해요.

> 시트 첫 행에 `id | createdAt | url | title | description | keywords | author` 열이 자동으로 생겨요.
> 잘못 뽑힌 키워드나 제목은 시트에서 바로 고치면 화면에도 반영돼요.

## 회사 메일 인증 켜기 (이미 시트를 연결한 경우)

1. Apps Script 편집기에 바뀐 `apps-script.gs`를 통째로 다시 붙여넣고 저장해요.
2. 위쪽 함수 목록에서 `authorizeMail`을 고르고 **실행** → 권한 검토 → 허용 (메일 보내기 권한이 새로 필요해요).
3. **배포 → 배포 관리 → 연필 → 버전: 새 버전 → 배포**. 웹 앱 주소는 그대로라 `API_URL`은 안 바꿔도 돼요.
4. 바뀐 `index.html`을 커밋·푸시해요. (3과 4 사이에는 예전 화면이 목록을 못 불러와요)
5. 회사 메일로 인증번호가 잘 오는지 한 번 해 봐요. 안 오면 스팸함, 또는 회사 메일 차단 설정을 확인해요.

- 허용 도메인은 `ALLOWED_DOMAINS`, 로그인 유지 기간은 `SESSION_DAYS`에서 바꿔요.
- 퇴사자 등을 바로 내보내려면 `REVOKE_TARGET`에 메일 주소를 넣고 `revokeEmail`을 실행해요.

## Apps Script를 고쳤을 때

**배포 → 배포 관리 → 연필(수정) → 버전: 새 버전 → 배포**를 눌러야 반영돼요.
(새 배포를 만들면 주소가 바뀌니 `API_URL`도 바꿔야 해요)

## 참고

- 웹 앱 액세스는 "모든 사용자"로 두어요. 접근 제한은 회사 메일 인증이 서버에서 처리해요. (회사 메일이 Google Workspace가 아니라서 "조직 내 사용자" 설정은 쓸 수 없어요)
- 키워드 추출 규칙(불용어·조사·점수)은 `apps-script.gs`의 `STOPWORDS`, `KO_SUFFIXES`, `extractKeywords`에 있어요. 편집기에서 `testExtract`를 실행하면 로그로 결과를 볼 수 있어요.
